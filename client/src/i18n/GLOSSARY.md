# Peekaboo localization glossary

This glossary is the copywriting source of truth for English, French, and Kinyarwanda UI terminology. French copy addresses users with **vous**. Kinyarwanda copy uses clear, respectful contemporary language and avoids unnecessary English loanwords. Brand names, payment-provider names, reference codes, currency codes, and protocol statuses remain unchanged.

## Style notes

- Use sentence case for headings and actions in all three languages.
- Prefer “commande” for the product object in French; reserve “livraison” for the physical service or journey.
- Use “komande” consistently for the product object in Kinyarwanda. Use “itangwa” or a natural verb such as “gushyikiriza” for the physical delivery.
- Keep `RWF`, `OTP`, order references, email addresses, street addresses, Peekaboo, MTN MoMo, Airtel Money, Google, Mapbox, and WhatsApp unchanged.
- Translate user-visible status labels, but never translate the server enum values used by APIs.
- Legal translations must preserve the English meaning and require final review by qualified Rwandan legal counsel before publication.
